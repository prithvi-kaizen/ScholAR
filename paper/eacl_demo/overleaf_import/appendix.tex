\section{Prompt Templates and Generation Protocol}
\label{app:prompts}

The answer generation pipeline utilizes a structured system prompt designed to enforce factual citations and prevent hallucinated references.

\begin{quote}
\small\ttfamily
You are a precise scientific research assistant. You are given a user question and a numbered set of verified evidence excerpts from a scientific paper.

Answer the question strictly using the provided evidence excerpts. Every factual claim, quantitative value, or mathematical statement MUST be followed immediately by one or more citation markers referencing the exact excerpt number, e.g., [1] or [1, 2].

Do not introduce external knowledge or facts not present in the excerpts. If the provided excerpts do not contain sufficient evidence to answer the question, state clearly: "The provided paper sections do not contain sufficient information to answer this question."
\end{quote}

Evidence items presented in the prompt follow a strict template:
\begin{quote}
\small\ttfamily
[Excerpt 1] (Page 4, Section 3.2)\\
"We train our model using Adam with beta1=0.9, beta2=0.999, and a learning rate of 2e-4..."
\end{quote}

\section{Artifact Schema and Execution Trace}
\label{app:trace_schema}

Every question answering interaction produces a validated JSON execution trace recorded under \texttt{backend/data/traces/}. The trace structure includes:
\begin{itemize}[leftmargin=*,itemsep=1pt,topsep=2pt]
    \item \texttt{query\_id}: Unique UUID for the transaction;
    \item \texttt{paper\_id}: Ingested document identifier;
    \item \texttt{raw\_query}: Raw natural language question;
    \item \texttt{retrieved\_chunks}: Ranked list of chunk IDs, fusion scores, page numbers, and normalized bounding boxes $[x_0, y_0, x_1, y_1]$;
    \item \texttt{raw\_completion}: Unmodified text emitted by the generator;
    \item \texttt{verifier\_actions}: List of remapping or pruning operations executed by the consistency verifier;
    \item \texttt{final\_answer}: Verified answer with synchronized citation chips;
    \item \texttt{latency\_breakdown}: Latency in milliseconds across retrieval, inference, and verification.
\end{itemize}

\section{Detailed Hardware Profiling}
\label{app:hardware}

Profiling was conducted on an Apple M3 Pro (12 CPU cores, 18 GPU cores, 18\,GB unified memory, macOS 15.1). The local model backend was Ollama v0.5.12 serving \texttt{qwen3.5:9b} with Q4\_K\_M quantization. The audited 100-request local profile is reported in Section~\ref{sec:evaluation}; it establishes feasibility on this workstation, not throughput or responsiveness at scale.
