# Overleaf import

Upload the contents of this folder to a new Overleaf project, then set
`main.tex` as the main document and compile with pdfLaTeX. The folder contains
only the manuscript sources, ACL style files, figures, tables, bibliography,
and the evaluation gate file required by `main.tex`.

The package and screencast URLs are intentionally not invented in this draft.
Insert the real release links in `sections/availability.tex` before submission.
