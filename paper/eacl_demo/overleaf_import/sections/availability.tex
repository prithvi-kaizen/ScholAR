\section{Availability and Reproducibility}
\label{sec:availability}

\paragraph{Access.}
\textsc{ScholAR} is MIT-licensed; its source is at \url{https://github.com/prithvi-kaizen/ScholAR}. The final submission will add a signed-out-accessible, versioned ZIP URL with a SHA-256 checksum and a screencast URL (no longer than 2.5 minutes). The release contains a self-authored example PDF; private papers, caches, traces, and model weights are excluded.

\paragraph{Tested environment.}
The verified profile uses Python 3.12, Node.js 20/npm 10, Ollama, and a Q4\_K\_M \texttt{qwen3.5:9b} model on an Apple M3 Pro with 18\,GB unified memory.
