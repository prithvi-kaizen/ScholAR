\section{Conclusion}
\label{sec:conclusion}

We presented \textsc{ScholAR}, a local-first scientific-paper assistant built around one interaction: ask a question, then inspect the exact source region attached to each citation. Layout-aware evidence objects, hybrid retrieval, deterministic checks, and an execution trace support that interaction without turning provenance into a claim of factual entailment. The retrospective diagnostics show useful retrieval and feasible local operation, while also showing why lexical repair and model judgments require caution. The demo's contribution is an inspectable workflow for researchers, reviewers, and students; its package and screencast must make that workflow directly testable.
