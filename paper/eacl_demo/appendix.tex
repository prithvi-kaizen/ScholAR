\section{Supplementary Audit Artifacts}
\label{app:artifacts}

The release preserves the machine-readable evaluation tables, the guarded human-evaluation macros, and the JSON trace schema used by the demonstration. These supplementary artifacts support reproduction without adding provisional human outcomes to the paper.

\subsection{Generation contract}
\label{app:generation-contract}

The generator receives a numbered set of application-owned evidence excerpts. The release prompt instructs the model to answer only from those excerpts, attach one or more markers (for example, \texttt{[1]} or \texttt{[1, 2]}) to each factual, numerical, or mathematical claim, and state explicitly when the supplied evidence is insufficient. The model proposes markers but never assigns page numbers or coordinates; the application resolves markers to the source-scoped evidence identities retained in the trace.

\subsection{Reproduction checklist}
\label{app:reproduction}

The installable package is intended to make the demonstration inspectable in four steps: (i) start the local backend and frontend, (ii) load the self-authored example PDF included with the release, (iii) ask a text or visual question and open a citation, and (iv) export the JSON trace and inspect the linked page region. The tested local profile is documented in Section~\ref{sec:evaluation-details}; private papers, caches, traces, and model weights are not bundled.

\subsection{Evaluation-status boundary}
\label{app:evaluation-boundary}

The machine-readable retrieval, language-model audit, repair diagnostic, and hardware-profile artifacts are included for reproducibility. The human-evaluation gate remains closed until the planned ratings and quality checks are complete; this appendix therefore contains no provisional human aggregates.
