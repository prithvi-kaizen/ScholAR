\section*{Ethical Considerations}
\label{sec:ethics}

\paragraph{Privacy and local execution.}
\textsc{ScholAR} is intended for unpublished manuscripts, review drafts, and proprietary notes. In strict-local analysis mode, the network policy blocks non-loopback requests. Users must still distinguish that analysis boundary from any explicitly enabled document, model, or reference acquisition.

\paragraph{Copyright and redistribution.}
The demonstration package and public repositories do not redistribute copyrighted publications without authorization. Benchmarks and tutorial examples use open-access preprints distributed under Creative Commons or arXiv non-exclusive licenses.

\paragraph{Evaluators and consent.}
The five-rater offline study protocol was prepared, but no ratings had been returned at the manuscript freeze. If recruitment proceeds, evaluators will provide informed consent and use pseudonymous identifiers (e.g., \texttt{R01}--\texttt{R05}); public aggregates will not expose contact details or identifiable comments.

\paragraph{External models.}
Secondary evaluation with an external model requires explicit operator authorization and sets \texttt{store=false}. Users are told that external APIs are not zero-retention environments.
