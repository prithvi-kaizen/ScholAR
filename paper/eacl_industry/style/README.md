# Official ACL style installation gate

The EACL 2027 Industry Track requires the official, unmodified ACL style and warns that nonconforming papers can be rejected without review. This repository intentionally does not synthesize or alter that third-party template.

Before a submission build, download the current files linked by the [official EACL 2027 Industry Track call](https://2027.eacl.org/calls/industry/) from the [official ACL style repository](https://github.com/acl-org/acl-style-files), then place at least `acl.sty` and `acl_natbib.bst` in this directory. Record the upstream commit in `UPSTREAM_COMMIT.txt`. Do not edit those files.

The submission validator fails until these files exist and all study gates are cleared. General [ACL formatting guidance](https://acl-org.github.io/ACLPUB/formatting.html) additionally requires A4 PDF, embedded fonts, the review ruler, two columns, and an abstract no longer than 200 words; the Industry Track call’s six-page review limit takes precedence over the generic long/short limits.
