\begin{tcolorbox}[title=Executive Summary, colback=lightbg, colframe=primary]
ScholAR is an on-device AI research assistant that operates 100\% locally via Ollama:
\begin{itemize}[leftmargin=1.5em, itemsep=2pt]
    \item \textbf{Zero Cloud Leakage:} Ingests arXiv papers or custom PDFs; inference, vision processing, and embeddings remain entirely on-device.
    \item \textbf{Verifiable Citations:} Maps short-lived evidence tokens (\texttt{[E1]}, \texttt{[E2]}) to immutable PDF pages, eliminating hallucinated page numbers.
    \item \textbf{Visual Grounding:} Directly routes figure and table queries to a local Vision LLM with high-resolution 3$\times$ zoom image crops.
    \item \textbf{Multi-Document Reasoning:} Resolves bibliographies via Semantic Scholar API to dynamically ingest and cross-read referenced works.
\end{itemize}
\end{tcolorbox}

\section{Deep-Dive into RAG Pipeline Components}

\subsection{1. Ingestion \& Page-Preserving Chunking Strategy}
Standard RAG frameworks split text by arbitrary token lengths, frequently cutting across page boundaries. When an LLM cites that chunk, it cannot point to an exact single page.
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Our Rule:} $\text{One Chunk} \in \text{One Page}$. No chunk ever spans across multiple pages.
    \item \textbf{Sliding Window Parameters:} Target word count = 1400 words, word overlap = 120 words per page.
    \item \textbf{Visual Crop Extraction:} Bounding box detection automatically crops figures/tables at \textbf{3$\times$ zoom} for optical clarity.
\end{itemize}

\subsection{2. Embedding Model \& Primary Retrieval Engine}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Lexical Primary (BM25):} Used as the primary signal because scientific literature requires exact matching on numbers, dataset names, formulas, and parameters (e.g., \textit{BLEU 28.4}, \textit{lr=1e-4}, \textit{WMT14}).
    \item \textbf{Dense Embedding Model:} Pure PyTorch implementation of \texttt{all-MiniLM-L6-v2} (384-dimensional dense vectors). Runs completely locally without heavy external dependencies.
    \item \textbf{Reciprocal Rank Fusion (RRF, $k=60$):} Combines lexical and dense ranks for research evaluation:
    $$\text{RRF Score}(d) = \frac{1}{60 + \text{Rank}_{\text{BM25}}(d)} + \frac{1}{60 + \text{Rank}_{\text{Dense}}(d)}$$
\end{itemize}

\subsection{3. Heuristic Re-Ranking Boosts}
Before passing chunks to the LLM, BM25 scores are dynamically adjusted based on query intent:
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Page Hint Boost (+1.25):} If the query asks \textit{"What is discussed on page 4?"}, page 4 chunks are prioritized.
    \item \textbf{Section Hint Boost (+0.5 to +1.0):} Boosts Abstract, Methods, Results, or Limitations sections when implied.
    \item \textbf{Visual Cue Boost (+1.5):} If a query mentions \textit{"Figure 2"} or \textit{"Table 1"}, figure chunks jump to Rank 1.
    \item \textbf{Query Expansion:} Synonym expansion for research vocabulary (e.g., \textit{result} $\rightarrow$ \textit{accuracy, BLEU, F1, score}).
\end{itemize}

\subsection{4. Multimodal Vision Routing}
When a query targets a visual element:
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item Retrieval ranks the figure chunk as top-1.
    \item The high-resolution 3$\times$ zoom PNG crop of that figure is base64-encoded.
    \item Sent directly to the local Vision LLM (\texttt{qwen3.5:9b} or \texttt{gemma4:12b}) along with the question.
    \item \textbf{Caption Fallback:} If the vision model is unreachable, it automatically falls back to caption text QA.
\end{enumerate}

\subsection{5. Indirect Evidence ID Citation Grounding}
To eliminate invented or hallucinated page numbers:
\begin{enumerate}[leftmargin=1.5em, itemsep=1pt]
    \item \textbf{Prompt Ingestion:} Retrieved chunks are labeled as \texttt{[E1]}, \texttt{[E2]}, \texttt{[E3]} in the LLM prompt.
    \item \textbf{Constrained Output:} The model is strictly instructed to cite using only \texttt{[E1]}, \texttt{[E2]} and cannot write page numbers.
    \item \textbf{Application Translation:} Backend maps \texttt{[E1]} to the source chunk's verified metadata $\rightarrow$ rendering a clickable \textbf{[1] (Page 3)} chip in the UI.
    \item \textbf{Guarantee:} \textbf{100\% of cited page numbers exist on real PDF pages by construction.}
\end{enumerate}

\subsection{6. Multi-Document Expansion (Citation Graph)}
\begin{itemize}[leftmargin=1.5em]
    \item \textbf{Semantic Scholar API:} Queries S2 by arXiv ID or paper title to fetch up to 500 reference papers.
    \item \textbf{On-Demand Ingestion:} Users can ingest any cited paper with one click. It is downloaded, chunked, and tagged with \texttt{source\_paper\_id}.
    \item \textbf{Cross-Paper Retrieval:} Queries search across the anchor paper and all ingested secondary papers simultaneously.
\end{itemize}

\section{Critical Research Takeaways (Honest Findings)}

\begin{enumerate}[leftmargin=1.5em, itemsep=4pt]
    \item \textbf{Cosine Faithfulness Inflates Scores by 2$\times$:} Embedding cosine similarity cannot catch contradictions (\textit{"Model A works"} vs \textit{"Model A fails"} look identical in vector space). Our strict LLM Entailment Judge fixes this and provides honest grounding metrics ($\sim$0.61 vs inflated $\sim$0.85).
    \item \textbf{Provenance vs. Faithfulness:} Ephemeral evidence IDs guarantee that 100\% of cited page numbers exist, but claim support still depends on retrieval quality (66\% support rate). ID grounding buys provenance and auditability.
    \item \textbf{The M3SciQA Win:} Breaking figure questions into two steps (Vision VLM reads figure $\rightarrow$ BM25 ranks bibliography) delivers \textbf{0.474 MRR} locally—beating open-source baselines and approaching GPT-4o.
\end{enumerate}
